# Roadmap

## 0.1.x

- Stabilize image workflow and packaging.
- Add optional application icon and signed packages.
- Improve performance profiling for large error-diffusion exports.

## 0.2

- Reorderable effect stack.
- Crop / rotate / resize nodes.
- Blur, sharpen, posterize, color shift, grain, glow, and channel effects.
- Before/after split view.
- Project files that store effect stacks and source references.

## 0.3

- GIF/APNG import and export.
- Video decode/encode through FFmpeg.
- Frame cache and proxy preview.
- Timeline playback.

## 0.4

- Keyframeable parameters and easing.
- Temporal noise and frame-dependent effects.
- Batch processing queue.
- Plugin API for processing nodes and dithering kernels.
